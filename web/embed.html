Draw a house from a JSON file

Two script tags and one call, in the spirit of JSqfd: HOQ.draw(element, houseOrUrl, options). Options: reduce hides rows and columns with no relationship, symbols:false shows 9 3 1 instead of ● ○ △, mode:'gap' weights needs by importance × (goal ÷ today), roof:false leaves the roof out. Loading from a URL needs the page served over http (a file:// page cannot fetch); an object works anywhere.

<script src="hoq-core.js"></script>
<div id="hoq"></div>
<script>HOQ.draw('#hoq', '../examples/sample-house.json', { reduce: true });</script>
